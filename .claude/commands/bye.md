세션을 마무리합니다. 아래 절차를 순서대로 실행해주세요.

## 1. 기존 daily-log.md 읽기

`.claude/memory/daily-log.md` 파일을 먼저 읽으세요.

## 2. 이번 세션 내용 분석

이번 세션의 대화 전체를 검토해서 다음을 파악하세요:
- 이번 세션에서 완료한 작업
- 미완료이거나 다음에 이어서 해야 할 작업
- 막힌 부분이나 보류 중인 결정
- 관련된 주요 파일 경로

## 3. daily-log.md 업데이트

기존 내용과 이번 세션 내용을 **통합**해서 덮어쓰세요.

**섹션별 규칙:**
- `## 마지막 작업일` → 오늘 날짜로 갱신
- `### ✅ 완료한 작업` → 기존 항목 유지 + 이번 세션 완료 항목 추가
- `### 🔄 다음에 이어서 할 작업` → 기존 항목 중 아직 미완료인 것 유지 + 이번 세션의 새 미완료 항목 추가. 이번 세션에서 완료된 기존 항목은 제거하고 ✅ 완료 목록으로 이동
- `### ⚠️ 막힌 부분 / 보류 중인 결정` → 해결된 것은 제거, 새로운 것 추가 (없으면 섹션 생략)
- `### 📁 관련 파일` → 기존 목록 유지 + 새 파일 추가 (중복 제거)
- `## 📋 일보고 기록` → 이번 세션을 일보고 형식으로 새 항목 추가 (기존 항목 유지, 최신이 위로)

**형식:**
```
# Daily Work Log

<!-- bye 스킬이 자동으로 업데이트합니다. 직접 수정하지 마세요. -->

## 마지막 작업일: YYYY-MM-DD

### ✅ 완료한 작업
- 항목 — YYYY-MM-DD

### 🔄 다음에 이어서 할 작업
- 항목 (간단한 컨텍스트 포함)

### ⚠️ 막힌 부분 / 보류 중인 결정
- 내용 (없으면 이 섹션 생략)

### 📁 관련 파일
- `경로/파일명` — 한 줄 설명

---

## 📋 일보고 기록

### YYYY-MM-DD 일보

1. 작업 내용
   1. 항목1
   2. 항목2

2. 결과 / 변경사항
   1. 항목

3. 다음 세션 예정
   1. 항목

---

(이전 일보들이 아래에 계속 이어짐)
```

## 4. git 커밋 & 푸시

```bash
git add .claude/memory/daily-log.md
git commit -m "chore: daily log YYYY-MM-DD"
git push
```
