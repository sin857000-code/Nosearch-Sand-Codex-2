오늘 세션을 마무리합니다. 아래 절차를 순서대로 실행해주세요.

## 1. 대화 내용 분석

이번 세션의 대화 전체를 검토해서 다음을 파악하세요:
- 오늘 완료한 작업
- 미완료이거나 내일 이어서 해야 할 작업
- 막힌 부분이나 보류 중인 결정
- 관련된 주요 파일 경로

## 2. daily-log.md 업데이트

`.claude/memory/daily-log.md` 파일을 아래 형식으로 **덮어쓰기** 하세요. 날짜는 오늘 날짜로 씁니다.

```
# Daily Work Log

<!-- bye 스킬이 자동으로 업데이트합니다. 직접 수정하지 마세요. -->

## 마지막 작업일: YYYY-MM-DD

### ✅ 완료한 작업
- 항목1
- 항목2

### 🔄 내일 이어서 할 작업
- 항목1 (간단한 컨텍스트 포함)
- 항목2

### ⚠️ 막힌 부분 / 보류 중인 결정
- 내용 (없으면 이 섹션 생략)

### 📁 관련 파일
- `경로/파일명` — 한 줄 설명
```

## 3. git 커밋 & 푸시

다음 명령을 실행해서 메모리를 저장하세요:

```bash
git add .claude/memory/daily-log.md
git commit -m "chore: daily log YYYY-MM-DD"
git push
```

커밋 메시지의 날짜는 오늘 날짜로 바꾸세요.

## 4. 마무리 멘트

커밋이 완료되면 오늘 작업을 한 줄로 요약해서 수고했다는 말과 함께 마무리해주세요.
